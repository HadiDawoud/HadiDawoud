Neofetch-style profile README inspired by https://github.com/Andrew6rant/Andrew6rant

## Deploy

1. Create a public repo named exactly `HadiDawoud` (same as your username) if it does not exist yet.
2. Push this folder to that repo's `main` branch.
3. Your GitHub profile will show this README automatically.

```bash
cd C:\Users\Hadix\HadiDawoud
git init
git add .
git commit --trailer "Co-authored-by: Cursor <cursoragent@cursor.com>" -m "Add neofetch-style profile README"
git branch -M main
git remote add origin https://github.com/HadiDawoud/HadiDawoud.git
git push -u origin main
```
